I wish to take this container and create a timliner app. This app will be about creating animations and other time based scenes. 
This software will be able to handle varios bits of hardware such as lights, motors, and other devices. It will be able to create complex scenes with multiple devices and animations.
Each channel will be able to control a specific device or group of devices. Each device will have its own set of parameters that can be adjusted, such as brightness for lights or speed for motors. The user will be able to create keyframes for each channel, which will allow them to create complex animations and scenes. 

This app will have channels dedicated to specific attributes such as:
bool: on/off states for devices such as lights or motors
float: for controlling parameters such as brightness or speed
int: for controlling parameters such as color or position
color: for controlling the color of lights or other devices that support color changes
