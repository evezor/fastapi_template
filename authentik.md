# Authentik Authentication Implementation Plan

## Overview

This document outlines the implementation plan for integrating Authentik authentication into the FastAPI application at `home.evezor.com` with Single Sign-On (SSO) support for `floe.evezor.com`.

**Authentik Server**: `auth.evezor.com`
**Primary App**: `home.evezor.com` (FastAPI with frontend)
**Secondary App**: `floe.evezor.com` (will share authentication)

### Container Architecture

This application is **containerized using Docker** and managed with **docker-compose**:
- **Base Image**: Python 3.12-slim
- **Container Name**: `home` (FastAPI service)
- **Port**: 8000 (exposed to host)
- **Development**: Hot-reload enabled via volume mounts (`./app:/app`)
- **Production**: Multi-worker uvicorn without volume mounts
- **Environment**: Variables loaded from `.env` file

**Project Structure**:
```
fastapi_template/
├── docker-compose.yml      # Container orchestration
├── .env                     # Environment variables
├── app/
│   ├── Dockerfile          # Container image definition
│   ├── requirements.txt    # Python dependencies
│   ├── main.py             # FastAPI application
│   ├── auth/               # Authentication module (to be created)
│   ├── htmldirectory/      # Templates
│   └── static/             # Static files
```

## Architecture Decisions

### Selected Approach
- **Flow**: OAuth2 Authorization Code Flow with PKCE
- **Token Strategy**: JWT tokens (access + refresh) - stateless
- **SSO**: Full Single Sign-On between home.evezor.com and floe.evezor.com
- **Token Validation**: Local validation using Authentik's JWKS public keys
- **User Data**: Basic profile + groups/roles for authorization
- **Token Refresh**: Automatic refresh using refresh tokens
- **Cross-App Auth**: Shared audience configuration

### Benefits of This Approach
✅ **Security**: Authorization Code Flow is the most secure OAuth2 flow
✅ **Scalability**: Stateless JWT validation, no server-side session storage
✅ **Performance**: Local token validation with public keys (no network calls per request)
✅ **User Experience**: Full SSO - login once, access both apps seamlessly
✅ **Flexibility**: Groups and roles enable fine-grained authorization
✅ **Modern**: Industry-standard OIDC implementation

### Tradeoffs to Consider
⚠️ **Token Revocation**: JWTs can't be revoked until expiry (mitigation: short-lived access tokens + refresh tokens)
⚠️ **Token Size**: JWTs with groups/roles can be large (typical: 1-3KB)
⚠️ **Clock Skew**: Token validation requires synchronized clocks (NTP recommended)
⚠️ **Key Rotation**: Need to handle Authentik key rotation gracefully (JWKS caching with TTL)

## Implementation Plan

### Phase 1: Authentik Configuration

#### 1.1 Create OAuth2 Provider in Authentik

1. Navigate to `auth.evezor.com` admin panel
2. Go to **Applications** → **Providers** → **Create**
3. Select **OAuth2/OpenID Provider**
4. Configure:
   ```
   Name: home-evezor-oauth
   Client Type: Confidential
   Client ID: <auto-generated or custom>
   Client Secret: <generate secure secret>
   Redirect URIs:
     - https://home.evezor.com/auth/callback
     - http://localhost:8000/auth/callback (for local dev)
   Signing Key: <select or create>
   ```

5. **Scopes**: Configure which user data the application can access

   **What are scopes?**
   Scopes are permissions that define what user information your application can access. When users log in, they grant your app permission to access specific data (email, profile, groups, etc.).

   **Required Scopes** (in Authentik admin panel):

   - **`openid`** (REQUIRED)
     - Core OAuth2/OIDC scope - enables authentication
     - Without this, OAuth2 won't work
     - Returns the `sub` (subject/user ID) claim in tokens

   - **`profile`** (RECOMMENDED)
     - Provides basic user profile information
     - Returns: `name`, `preferred_username`, `given_name`, `family_name`, `picture`, etc.
     - Needed to display user name in your app

   - **`email`** (RECOMMENDED)
     - Provides user's email address
     - Returns: `email`, `email_verified`
     - Essential for user identification and communication

   - **`groups`** (RECOMMENDED for role-based access)
     - Provides user's group memberships in Authentik
     - Returns: `groups` array (e.g., `["admin", "user"]`)
     - Enables role-based access control (RBAC) in your app
     - Used by the `require_group()` dependency (see Phase 2.5)

   **How to enable scopes in Authentik**:

   a. In Authentik admin (`auth.evezor.com`), go to **Applications** → **Providers**

   b. Click on your provider (`home-evezor-oauth`)

   c. Scroll to **"Protocol Settings"** section

   d. Find **"Scopes"** field - this is a multi-select dropdown

   e. Select these scopes (hold Ctrl/Cmd to select multiple):
      - `openid` (should be selected by default)
      - `email` (typically pre-configured in Authentik)
      - `profile` (typically pre-configured in Authentik)
      - `goauthentik.io/api` OR create a custom scope for groups (see below)

   f. Click **Save**

   **For Groups Scope** (if not available):

   If you don't see a `groups` scope or need to customize it:

   1. Go to **Customization** → **Property Mappings** → **Scope Mappings**

   2. Check if there's a mapping called "Groups" or similar

   3. If not, click **Create** → **Scope Mapping**:
      ```
      Name: Groups Scope
      Scope name: groups
      Description: User group memberships
      Expression:
      return {
          "groups": [group.name for group in user.ak_groups.all()]
      }
      ```

   4. Go back to your OAuth provider settings

   5. In the **Scopes** field, add your new "Groups Scope"

   **Verification**: After configuring scopes, when users log in:
   - They'll see a consent screen listing what data the app can access (unless you disable consent)
   - The access token will contain claims corresponding to the scopes (e.g., email, groups)
   - Your FastAPI app can read these claims from the JWT token (see `app/auth/models.py` - `TokenData` and `UserInfo` models)

6. **Advanced settings**:
   - Access token validity: `600` (10 minutes - short-lived)
   - Refresh token validity: `86400` (24 hours)
   - Subject Mode: `Based on User's UUID`

**`app/auth/jwks.py`**: Fetch and cache Authentik's public keys
```python
import httpx
import jwt
from jwt import PyJWKClient
from typing import Optional
from functools import lru_cache

class AuthentikJWKSClient:
    """Wrapper around PyJWT's PyJWKClient with async support"""

    def __init__(self, jwks_uri: str, cache_ttl: int = 300):
        """
        Initialize JWKS client

        Args:
            jwks_uri: Authentik JWKS endpoint URL
            cache_ttl: Cache time-to-live in seconds (default 5 minutes)
        """
        self.jwks_uri = jwks_uri
        # PyJWKClient handles caching and key rotation automatically
        self._client = PyJWKClient(
            uri=jwks_uri,
            cache_keys=True,
            max_cached_keys=16,
            cache_jwk_set_ttl=cache_ttl,
            lifespan=cache_ttl
        )

    def get_signing_key_from_jwt(self, token: str):
        """
        Get signing key for a JWT token

        PyJWKClient automatically:
        - Extracts kid from token header
        - Fetches from JWKS endpoint (with caching)
        - Handles key rotation
        - Retries if kid not found after cache refresh
        """
        return self._client.get_signing_key_from_jwt(token)

# Global singleton instance (initialized in dependencies.py)
_jwks_client: Optional[AuthentikJWKSClient] = None

def get_jwks_client(jwks_uri: str) -> AuthentikJWKSClient:
    """Get or create JWKS client singleton"""
    global _jwks_client
    if _jwks_client is None:
        _jwks_client = AuthentikJWKSClient(jwks_uri)
    return _jwks_client
```

**`app/auth/oauth.py`**: OAuth flow implementation
```python
from fastapi import HTTPException, status
from typing import Dict
import httpx
import secrets
from .config import AuthentikSettings
from .models import TokenResponse, UserInfo

class AuthentikOAuth:
    def __init__(self, settings: AuthentikSettings):
        self.settings = settings

    def get_authorization_url(self, state: str) -> str:
        """Generate authorization URL for OAuth flow"""
        params = {
            "client_id": self.settings.client_id,
            "response_type": "code",
            "redirect_uri": self.settings.redirect_uri,
            "scope": "openid profile email groups",
            "state": state,
        }
        query = "&".join([f"{k}={v}" for k, v in params.items()])
        return f"{self.settings.authorization_endpoint}?{query}"

    async def exchange_code_for_token(self, code: str) -> TokenResponse:
        """Exchange authorization code for tokens"""
        async with httpx.AsyncClient() as client:
            response = await client.post(
                self.settings.token_endpoint,
                data={
                    "grant_type": "authorization_code",
                    "code": code,
                    "redirect_uri": self.settings.redirect_uri,
                    "client_id": self.settings.client_id,
                    "client_secret": self.settings.client_secret,
                }
            )
            if response.status_code != 200:
                raise HTTPException(
                    status_code=status.HTTP_401_UNAUTHORIZED,
                    detail="Failed to exchange authorization code"
                )
            return TokenResponse(**response.json())

    async def refresh_access_token(self, refresh_token: str) -> TokenResponse:
        """Use refresh token to get new access token"""
        async with httpx.AsyncClient() as client:
            response = await client.post(
                self.settings.token_endpoint,
                data={
                    "grant_type": "refresh_token",
                    "refresh_token": refresh_token,
                    "client_id": self.settings.client_id,
                    "client_secret": self.settings.client_secret,
                }
            )
            if response.status_code != 200:
                raise HTTPException(
                    status_code=status.HTTP_401_UNAUTHORIZED,
                    detail="Failed to refresh token"
                )
            return TokenResponse(**response.json())

    async def get_userinfo(self, access_token: str) -> UserInfo:
        """Fetch user information from Authentik"""
        async with httpx.AsyncClient() as client:
            response = await client.get(
                self.settings.userinfo_endpoint,
                headers={"Authorization": f"Bearer {access_token}"}
            )
            if response.status_code != 200:
                raise HTTPException(
                    status_code=status.HTTP_401_UNAUTHORIZED,
                    detail="Failed to get user info"
                )
            return UserInfo(**response.json())
```

**`app/auth/dependencies.py`**: FastAPI dependencies for protected routes
```python
from fastapi import Depends, HTTPException, status, Cookie
from fastapi.security import HTTPBearer, HTTPAuthorizationCredentials
import jwt
from jwt.exceptions import InvalidTokenError, ExpiredSignatureError, InvalidAudienceError
from typing import Optional
from .jwks import get_jwks_client
from .config import AuthentikSettings
from .models import TokenData, UserInfo

security = HTTPBearer()
settings = AuthentikSettings()

async def verify_token(token: str) -> TokenData:
    """Verify JWT token using Authentik's public key from JWKS"""
    try:
        # Get JWKS client (singleton, handles caching)
        jwks_client = get_jwks_client(settings.jwks_uri)

        # Get signing key from JWT (PyJWKClient extracts kid automatically)
        signing_key = jwks_client.get_signing_key_from_jwt(token)

        # Verify and decode token with all security checks
        payload = jwt.decode(
            token,
            signing_key.key,
            algorithms=["RS256"],  # Only allow RS256
            audience=settings.client_id,  # Validate audience claim
            issuer=settings.domain,  # Validate issuer claim
            options={
                "verify_signature": True,
                "verify_exp": True,  # Check expiration
                "verify_aud": True,  # Check audience
                "verify_iss": True,  # Check issuer
                "require": ["exp", "iat", "sub"]  # Require these claims
            }
        )

        return TokenData(**payload)

    except ExpiredSignatureError:
        raise HTTPException(
            status_code=status.HTTP_401_UNAUTHORIZED,
            detail="Token has expired",
            headers={"WWW-Authenticate": "Bearer"}
        )
    except InvalidAudienceError:
        raise HTTPException(
            status_code=status.HTTP_401_UNAUTHORIZED,
            detail="Invalid token audience",
            headers={"WWW-Authenticate": "Bearer"}
        )
    except InvalidTokenError as e:
        raise HTTPException(
            status_code=status.HTTP_401_UNAUTHORIZED,
            detail=f"Invalid token: {str(e)}",
            headers={"WWW-Authenticate": "Bearer"}
        )
    except Exception as e:
        # Catch-all for unexpected errors
        raise HTTPException(
            status_code=status.HTTP_401_UNAUTHORIZED,
            detail="Could not validate credentials",
            headers={"WWW-Authenticate": "Bearer"}
        )

async def get_current_user(
    credentials: HTTPAuthorizationCredentials = Depends(security)
) -> TokenData:
    """Dependency to get current authenticated user from Bearer token"""
    token = credentials.credentials
    return await verify_token(token)

async def require_group(required_groups: list[str]):
    """Dependency factory for role-based access control"""
    async def check_groups(user: TokenData = Depends(get_current_user)) -> TokenData:
        if not any(group in user.groups for group in required_groups):
            raise HTTPException(
                status_code=status.HTTP_403_FORBIDDEN,
                detail=f"User must be in one of these groups: {required_groups}"
            )
        return user
    return check_groups

# Example usage:
# @app.get("/admin")
# async def admin_route(user: TokenData = Depends(require_group(["admin"]))):
#     return {"message": "Admin access granted"}
```

#### 2.6 Authentication Routes

Add to `app/main.py` or create `app/routers/auth.py`:
```python
from fastapi import APIRouter, HTTPException, Response, Cookie
from fastapi.responses import RedirectResponse
import secrets
from typing import Optional
from app.auth.oauth import AuthentikOAuth
from app.auth.config import AuthentikSettings

router = APIRouter(prefix="/auth", tags=["authentication"])
settings = AuthentikSettings()
oauth_client = AuthentikOAuth(settings)

# In-memory state storage (use Redis in production)
oauth_states = {}

@router.get("/login")
async def login():
    """Redirect user to Authentik for authentication"""
    state = secrets.token_urlsafe(32)
    oauth_states[state] = True  # Store state to verify later

    auth_url = oauth_client.get_authorization_url(state)
    return RedirectResponse(url=auth_url)

@router.get("/callback")
async def auth_callback(
    code: str,
    state: str,
    response: Response
):
    """Handle OAuth callback from Authentik"""
    # Verify state to prevent CSRF
    if state not in oauth_states:
        raise HTTPException(status_code=400, detail="Invalid state parameter")

    oauth_states.pop(state)  # Remove used state

    # Exchange code for tokens
    token_response = await oauth_client.exchange_code_for_token(code)

    # Get user info
    user_info = await oauth_client.get_userinfo(token_response.access_token)

    # Set tokens in httponly cookies (secure in production)
    response.set_cookie(
        key="access_token",
        value=token_response.access_token,
        httponly=True,
        secure=True,  # HTTPS only
        samesite="lax",
        max_age=600  # 10 minutes
    )

    if token_response.refresh_token:
        response.set_cookie(
            key="refresh_token",
            value=token_response.refresh_token,
            httponly=True,
            secure=True,
            samesite="lax",
            max_age=86400  # 24 hours
        )

    # Redirect to home page
    return RedirectResponse(url="/", status_code=303)

@router.post("/refresh")
async def refresh_token(
    refresh_token: Optional[str] = Cookie(None),
    response: Response = None
):
    """Refresh access token using refresh token"""
    if not refresh_token:
        raise HTTPException(status_code=401, detail="No refresh token provided")

    token_response = await oauth_client.refresh_access_token(refresh_token)

    response.set_cookie(
        key="access_token",
        value=token_response.access_token,
        httponly=True,
        secure=True,
        samesite="lax",
        max_age=600
    )

    return {"message": "Token refreshed successfully"}

@router.post("/logout")
async def logout(response: Response):
    """Logout user by clearing cookies"""
    response.delete_cookie("access_token")
    response.delete_cookie("refresh_token")

    # Optional: Redirect to Authentik logout
    # return RedirectResponse(url=f"{settings.domain}/application/o/<app-slug>/end-session/")

    return {"message": "Logged out successfully"}
```

// api.js - Axios interceptor for token refresh
import axios from 'axios';

const api = axios.create({
    baseURL: 'https://home.evezor.com',
    withCredentials: true  // Send cookies
});

// Intercept 401 errors and refresh token
api.interceptors.response.use(
    response => response,
    async error => {
        const originalRequest = error.config;

        if (error.response.status === 401 && !originalRequest._retry) {
            originalRequest._retry = true;

            try {
                await axios.post('/auth/refresh', {}, { withCredentials: true });
                return api(originalRequest);
            } catch (refreshError) {
                // Refresh failed, redirect to login
                window.location.href = '/auth/login';
                return Promise.reject(refreshError);
            }
        }

        return Promise.reject(error);
    }
);

export default api;

### Phase 4: Security Best Practices

#### 5.1 Token Security
- ✅ Use `httponly` cookies to prevent XSS attacks
- ✅ Use `secure` flag (HTTPS only)
- ✅ Use `samesite=lax` to prevent CSRF
- ✅ Short-lived access tokens (10 minutes)
- ✅ Rotate refresh tokens on use (if Authentik supports)

#### 5.2 HTTPS Requirements
- ✅ **Mandatory**: All apps must use HTTPS in production
- ✅ Use Let's Encrypt or similar for SSL certificates
- ✅ Configure reverse proxy (nginx/traefik) for TLS termination

### Troubleshooting Common Issues

| Issue | Possible Cause | Solution |
|-------|---------------|----------|
| 401 Unauthorized | Token expired | Implement automatic refresh |
| Invalid signature | Wrong public key | Check JWKS endpoint and cache |
| CORS errors | Missing credentials flag | Set `withCredentials: true` |
| SSO not working | Different audiences | Use shared audience config |
| Redirect loop | State validation failing | Check state storage (use Redis) |
| Container won't start | Missing dependencies | Rebuild: `docker-compose build home` |
| Changes not reflected | Volume not mounted | Check `docker-compose.yml` volumes |
| Can't connect to container | Wrong port mapping | Verify ports in `docker-compose.yml` |
| Environment vars not loaded | `.env` not found | Check `.env` file exists in project root |
| Module not found | Package not installed | Add to `requirements.txt` and rebuild |

## Production Deployment Notes

### Container Deployment Best Practices

1. **Use orchestration**: Deploy with Docker Compose, Docker Swarm, or Kubernetes
2. **Remove development features**: Disable hot-reload, remove volume mounts
3. **Use multi-worker mode**: `--workers 4` (adjust based on CPU cores)
4. **Implement health checks**: Monitor container health
5. **Use secrets management**: Docker secrets or Kubernetes secrets for sensitive data
6. **Set resource limits**: Prevent resource exhaustion
   ```yaml
   deploy:
     resources:
       limits:
         cpus: '2'
         memory: 1G
       reservations:
         cpus: '1'
         memory: 512M
   ```

7. **Use reverse proxy**: nginx or Traefik in front of containers
8. **Enable logging**: Centralized logging (ELK stack, Loki)
9. **Monitor metrics**: Prometheus + Grafana for observability
10. **Backup strategy**: Regular backups of volumes and secrets
